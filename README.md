# ComfyUI Studio

通过 AI 对话或聊天指令使用 ComfyUI 的 KiraAI 插件，支持文生图、图生图与每位用户独立的绘图配置。

当前版本：**0.0.1**。更新内容见 [CHANGELOG.md](CHANGELOG.md)。

配置页支持连接状态、未保存提醒、Ctrl/Cmd+S 保存、任务缩略图与自动刷新，适配手机与暗色主题。
保存配置后，已提交的任务继续使用原有设置；新任务使用新的配置。关闭插件、关闭绘图总开关或手动重载代码仍会取消正在运行的任务。
图床批量上传不完整时，整批图片改用媒体消息发送，避免遗漏。
配置的绘图模型不存在时会明确报错，请刷新列表重新选择。


## 安装与首次配置

- 已在 KiraAI 3.0.0 上测试，发布包最低版本设为 3.0.0；旧版未验证。
- 在 KiraAI 插件管理中使用本仓库地址安装，或导入 Release 中的 `comfyui_studio-0.0.1.zip`。
- 启用插件，在侧边栏「ComfyUI 绘图」填写 ComfyUI 地址并测试连接，再选择模型及配套编码器、VAE。
- `127.0.0.1` 指运行 KiraAI 的机器；ComfyUI 在其他机器时请填写其实际地址。
- 运行环境需提供 `httpx`、`Pillow` 和 KiraAI 自带的 FastAPI。模型与自定义节点由你的 ComfyUI 服务提供。
- AI 可以直接调用绘图工具；要使用聊天指令及分步设置，需手动开启「启用所有指令式功能」。
- 图床默认关闭。QQ Markdown 与按钮需要消息桥接插件及机器人对应权限；无按钮支持时设置向导提供文本指令选项。

本仓库只包含 KiraAI 插件，不包含独立桌面程序、模型、运行配置、令牌或用户数据。安装目录和插件编号保持为 `comfyui_studio`。

## AI 调用发送方式

AI 文生图和图生图只发送本地图片文件，不发送「正在生成」通知，不上传图床，也不发送 Markdown 或快捷按钮。后台任务完成后仍按相同方式发送文件；工具返回值要求 AI 不重复发图、链接或参数。指令调用保留原有进度通知及管理员配置的发送方式。

## 指令总开关

「聊天指令 → 启用所有指令式功能」默认关闭。关闭时，文生图、图生图、放大、模型/LoRA 查询、个人设置及所有指令按钮回调（包括历史按钮）均不可执行；插件会拦截这些指令，避免继续进入 AI 消息处理。新生成的图片不显示重试/放大按钮，原图链接保留。AI 文生图、图生图工具及网页配置管理仍可使用；AI 不能在关闭时打开按钮设置向导。

从旧版本升级时也需手动打开新开关，旧的 `command_enabled` 不会自动开启指令功能。以下聊天指令说明均以开启总开关为前提。

## 分步设置与个人配置

在聊天中只发送 `设置`（可自定义），或发送 `/comfy 设置`、`/comfy setup`，开始分步按钮选择：

1. 底模：使用已配置的模型预设，或全局默认底模。
2. 分辨率：选项按管理员的尺寸限制调整。
3. 张数：受单次最大张数限制。
4. LoRA：分页选择，每选一条单独选择强度，可继续添加，最多 8 条。支持不使用 LoRA 或沿用全局默认。
5. 确认并保存。

每次选择发送新消息；一条消息最多 5 行、每行最多 5 个按钮。按钮仅允许发起者使用，旧步骤与其他用户的按钮无法改动配置。
再次设置并完成保存后覆盖旧配置；取消或未完成时保留旧配置。向导 30 分钟后失效。
配置按适配器和用户编号独立保存在插件数据目录的 `user_settings.json`，插件或服务重启后继续可用。

完成后发送 `/comfy 一只猫在晒太阳`，自动使用你的底模、尺寸、张数与 LoRA。
原来的 `/comfy #模型 宽x高 [张数] [LoRA:强度] 提示词` 仍可临时覆盖参数；显式尺寸不填张数时沿用个人张数。
未设置的用户使用全局默认底模、1024×1024、1 张及全局默认 LoRA，尺寸仍受限制。
“正在生成”消息显示实际底模、尺寸、张数与已解析 LoRA；仅指令发起的文生图、图生图、再次生成和放大使用该提示，AI 调用不发送。

侧边页面的「用户配置」提供搜索、分页、编辑底模、尺寸、张数与 LoRA，并单独保存当前用户。
全局配置与个人配置分别保存；编辑时发生并发变更会提示重新读取，避免旧页面或未完成向导覆盖新值。
登录管理员可通过 `GET /api/plugin/comfyui_studio/user-settings` 和 `PUT /api/plugin/comfyui_studio/user-settings/{id}` 管理配置；更新须包含当前 `revision`。
AI 可调用 `comfyui_user_settings(action="start"/"show")` 打开本人向导或查看本人配置。

## 图生图与局部重绘

### 聊天工具

发送图片后直接说「把这张图改成水彩风格」，大模型使用 `comfyui_img2img` 工具。
原图按当前消息、引用消息、同一会话同一用户最近图片的顺序选择；可用 `image_index` 从 1 开始选择第几张。
引用消息无法取到图片时会要求重新附图，不会改用不相关的图片。最近图片默认有效 10 分钟，可在页面设为 0 关闭回溯。
多张输入默认只选择第一张；蒙版可用 `mask_index`，额外参考图可用 `reference_indices` 选择聊天附件序号，或通过 `mask_image`、`reference_images` 指定链接。

### 配置页面

网页用于管理连接、默认模型、图生图设置、预设、LoRA、图片发送与任务记录。
图生图设置集中管理默认重绘幅度、尺寸适配、工作流、原图限制及最近图片范围；图片按钮开关位于「图床与发送」。
在聊天中通过 AI 或指令发起生成，任务记录可以查看状态和成图。
宽高为 0 时跟随原图；只填写一边时保持原图比例。输出受生成像素、单边和张数上限限制。

### 直连指令

```text
[发送或引用一张图] /img2img 改成水彩插画
/img2img #1 auto -d 0.45 保留构图，改成柔和的水彩插画
/img2img #1 832x1216 2 [1:0.8] -d 0.6 --seed 123 提示词
/img2img --source https://example.com/source.png --mask https://example.com/mask.png 修改白色区域
/img2img -i 2 --fit crop 修改第二张图片
/img2img -i 1 --mask-index 2 --ref-index 3 修改蒙版白色区域，参考第三张图的风格
```

参数必须写在提示词前。`auto`、尺寸、张数与 LoRA 段均可省略；`-d` 表示重绘幅度，`-i` 表示图片序号。
`--ref` 可重复两次，添加额外参考图；仅 Qwen Image 2.1 / Edit Plus 支持。
`/comfy` 附带或引用图片时默认自动进入图生图（可关闭）；`/comfy --txt2img 宽x高 提示词` 强制文生图，`/comfy --img2img ...` 则使用图生图参数格式。

### 重绘、蒙版与模型

- 重绘幅度 `denoise` 为 0~1，越低越接近原图、越高变化越大；0 只执行尺寸适配，不进行采样。
- 尺寸适配支持等比留白（contain）、居中裁切（crop）和拉伸（stretch）。
- 蒙版须与原图同尺寸，白色重绘、黑色保留。使用 VAE 局部重绘并在输出阶段合成原图，保证黑色区域不被改动；批量张数保持一致。
- 通用图生图使用 LoadImage → VAEEncode → RepeatLatentBatch → KSampler，适用于现有 Anima、Krea2 等模型组合。
- 模型预设可指定「图生图工作流」，覆盖全局默认值：自动、通用 VAE、Qwen Edit、Qwen Edit Plus、Qwen Image 2.1。
- 自动模式按模型文件名识别 Qwen 2.1 与 Edit；Qwen Image 2.1 使用专用图像条件编码，尺寸向下对齐到 32 的倍数；额外参考图最多两张。
- 原生编辑应选用对应的编辑模型及配套编码器、VAE；插件支持其工作流接口，具体编辑效果取决于模型权重。
- 所有模式共用模型预设、LoRA、质量词和后台补发；AI 调用直接发文件，指令调用按管理员的发送设置处理。
- 输入默认限制为单张 20 MB、4000 万像素；支持 EXIF 方向校正、透明图铺白底、GIF 首帧，损坏文件与超限图片会明确报错。

### 任务查询 API

接口沿用 KiraAI 的登录认证，前缀为 `/api/plugin/comfyui_studio`。

| 接口 | 用途 |
| --- | --- |
| `GET /output-image/{job_id}/{index}` | 查看任务输出，index 从 0 开始 |
| `GET /jobs` | 查询任务进度；原图链接、临时凭据不会包含在公开任务记录中 |

图片输入由聊天附件、引用图片或显式 HTTP(S) 链接提供；仅可信消息元素可以提供本地路径。

### 图片快捷操作

开启指令总开关及「生成图消息底部挂按钮」后，指令生成的 Markdown 图片会附带再来一张、倍数放大与原图直链按钮，需要 QQ 消息桥接插件支持。
`/comfy again` 使用当前会话最近完成任务的提示词、预设和 LoRA，以新种子重画；图生图同时保留蒙版和参考图。
`/upscale` 放大当前会话最近一张成图并二次采样，倍数与重绘幅度可在「图生图设置」中调整；达到尺寸上限时先提示调整限制。

## 功能

- **大模型决定一切创作参数**：提示词内容、分辨率、张数、**底模预设**、LoRA 都由 LLM 通过 `comfyui_generate_image` 工具调用决定，插件只做上限钳制。可用模型预设列表会动态注入工具描述，LLM 按画面风格自行选择（动漫系→标签风格提示词，通用大模型系→自然语言提示词）。
- **内置质量词**：正面/负面质量词写死为默认值（可在 WebUI 中修改），大模型只写画面内容。
- **可选图床上传**：仅指令出图可使用，默认关闭且不预填第三方服务。配置自己的图床地址、上传接口和令牌后启用。
- **QQ 官方 Markdown 贴图与按钮**：指令调用可通过 [qqbot-fullmsg-bridge](https://github.com/znq19/KiraAI-qqbot-fullmsg-bridge) 发送 Markdown 图片与按钮，需要对应权限；AI 调用始终直接发送本地图片文件。
- **`/comfy` 直连指令**：绕过大模型直接出图（前缀可配置）。
- **WebUI 侧边栏配置页**：连接测试、模型/采样器下拉（实时读 `/object_info`）、像素/张数上限、质量词、图床设置、任务记录。

## 直连指令

```
@机器人 /comfy [#模型] 宽x高 [张数] [LoRA:强度,LoRA:强度] 提示词
@机器人 /comfy #1 832x1216 2 [久留美:0.8,age slider:0.5] 1girl, silver hair, cherry blossoms
@机器人 /comfy help                ← help 里会列出已配置的模型预设
@机器人 /model              ← 查看模型预设列表
@机器人 /lora [关键词]      ← 查看服务器可用 LoRA 列表
```

- `#模型`：切换整套预设（绘图模型+配套文本编码器+VAE，侧边栏「模型预设」里配置），支持编号（`#1`）或名称（可只写一部分）；省略则用上方「出图默认参数」。

- LoRA 段可省略（省略时只用侧边栏配置的「默认 LoRA」）；段内多条用**逗号**分隔（全角半角均可），**强度必填**（-1~2）。
- LoRA 可写**序号**（`/lora` 列表里的序号，如 `[1:0.8]`）或名称（可只写一部分，自动模糊匹配；多个匹配或无匹配会报错并列出候选，不开始生成）。
- 指令与侧边栏「默认 LoRA」会叠加，同名以指令指定的为准。

> ⚠️ **群里建议带 @ 机器人**：不带 @ 的消息走 `GROUP_MESSAGE_CREATE` 事件，机器人闲置时会被唤醒机制过滤；带 @ 的消息（`GROUP_AT_MESSAGE_CREATE`）必定送达。私聊无需 @。

- 宽高自动按 8 的倍数取整，超出「最大像素/单边」配置会被等比缩小。
- 张数超过「单次最大张数」会被钳制。
- 提示词建议使用英文 danbooru 风格标签（直连指令不经过大模型，不会自动翻译）。

## 模型预设

侧边栏「模型预设」卡片可配置多套完整组合（名称 + 绘图模型 + 文本编码器 + 编码器类型 + VAE + 精度 + **步数**），指令里用 `#1` / `#名称` 一键切换，配套组件与步数自动带上（步数留空则用全局默认）；`/comfy help` 会列出全部预设。

## 快捷按钮与放大

- 生成图消息底部自动挂按钮（`buttons_enabled` 可关）：**再来一张**（同参重抽）、**倍数放大**、**原图直链**
- `/comfy again`：重画最近一张（新种子）
- `/upscale`：把最近一张放大重采样（先放大像素 → 转潜空间 → 按 `upscale_denoise` 二次采样，默认 1.5 倍 / 0.8）
- 按钮依赖 qqbot-fullmsg-bridge；个别 QQ 版本按钮可能不渲染，不影响图片本身

## 发送链路说明

1. AI 工具同步等待生成；超过等待时间后任务仍在后台继续。
2. 成图下载到插件数据目录，直接以图片文件发到原会话，不发进度、参数、Markdown 或按钮。
3. 工具返回发送状态，要求 AI 不重复发送图片；发送失败会明确报告。
4. 指令调用先发送包含实际模型、尺寸、张数和 LoRA 的生成通知，再按发送设置交付图片。
5. 指令使用图床且上传失败时，改用图片媒体消息发送。

## 配置项

全部配置在 WebUI →「ComfyUI 绘图」侧边栏页（或插件配置弹窗）中修改，保存即热重载。

| 分组 | 关键项 |
| --- | --- |
| ComfyUI 连接 | `comfy_url`（默认 `http://127.0.0.1:8188`）、`request_timeout` |
| 生成限制 | `max_pixels`（默认 1024²）、`max_side`、`max_batch`、`sync_wait_seconds`、`job_timeout_seconds` |
| 出图默认 | `checkpoint`、`sampler`、`scheduler`、`steps`、`cfg` |
| 质量词 | `positive_quality` / `negative_quality` |
| 图床 | `bed_enabled`、`bed_base_url`、`bed_upload_path`、`bed_file_field`、`bed_token` |
| 发送 | `send_mode`（markdown / image） |
| 指令 | `command_features_enabled`、`command_prefix` |

## 注意

- ComfyUI 与 KiraAI 不在同一台机器时，ComfyUI 需以 `--listen 0.0.0.0` 启动。
- markdown 发送方式需要安装并启用 `qqbot-fullmsg-bridge` 插件，且机器人具备 markdown 权限。
- 上传令牌：若图床开启令牌校验，请在侧边栏「上传令牌」中填入网页上传框使用的令牌。
